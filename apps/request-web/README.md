# Request Web App Placeholder

This directory is reserved for the future guest request web app.

Wave 0B intentionally adds no mobile request routes, PWA shell, QR entry flow, kiosk mode, request screens, or request-submission behavior. Those features begin in later backlog waves.

Use `apps/request-web/.env.example` for safe demo-only configuration placeholders when the app is created.

`dev-proxy.config.json` documents the future local proxy shape for UI development. It is configuration only and does not start a web app.
