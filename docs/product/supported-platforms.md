# Supported Platforms

## First host-app release target

The first Windows host-app release targets fully patched, currently supported 64-bit Windows 11 systems.

## Pilot support policy

- Use Windows 11 64-bit for pilot validation.
- Keep the host laptop on a stable, supported Windows release before show use.
- Recheck Microsoft support dates before packaging a public installer.
- Do not rely on unsupported Windows versions for pilot or production shows.

## Not supported for the first release

- macOS and Linux host operation.
- Windows Server as a host-app desktop target.
- Unsupported or unpatched Windows releases.
- Mobile devices as host-app replacements.

## Future decision

If an operator needs another Windows version supported, document the exact release, support status, test coverage, and rollback plan in an ADR before accepting it.
