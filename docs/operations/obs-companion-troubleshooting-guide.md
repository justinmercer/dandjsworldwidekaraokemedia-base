
# OBS Companion Troubleshooting Guide

Static OBS and Replay companion troubleshooting notes.

## Common symptoms

- OBS preview is unavailable.
- Replay status is unclear.
- Lower-third metadata preview does not match expectations.
- Operator needs manual fallback.

## Safe response

- Document the symptom.
- Continue the show without automation if needed.
- Do not connect to OBS or Replay from this guide.
