
# Release-Blocker Criteria

Static release-blocker criteria for pilot readiness.

## Blockers

- Show cannot continue without manual fallback.
- Privacy or consent risk is unresolved.
- Operator cannot access core checklist docs.
- Known limitation is not documented.
- Recovery path is unclear.

## Non-blockers

- Minor wording issue.
- Minor layout polish.
- Future Phase 2 feature request.
- Cosmetic issue with clear workaround.

## Safety

This document does not automate release gating.
