
# Operator Quick-Start Guide

This static guide helps a host understand the pilot flow.

## Start

1. Review the pre-show checklist.
2. Confirm the venue setup.
3. Open the preview pages.
4. Keep manual fallback ready.

## During the show

1. Monitor requests.
2. Keep notes for issues.
3. Use known limitations to explain pilot boundaries.

## End

1. Review the post-show checklist.
2. Capture feedback.
3. Create bug-triage notes where needed.
