
# Host Troubleshooting Guide

Static host-side troubleshooting notes for pilot operators.

## Common symptoms

- App shell will not open.
- Preview page is missing.
- Operator cannot find the right checklist.
- Manual fallback is needed.

## Safe response

- Stop and document the symptom.
- Use the pre-show or post-show checklist.
- Use manual fallback if the pilot flow is blocked.
- Do not run unreviewed commands during a show.
