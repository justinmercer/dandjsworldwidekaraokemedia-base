
# Pilot-Show Go/No-Go Checklist

Use this static checklist before a pilot show.

## Go checks

- Host laptop opens the app shell.
- Demo catalog/search screens are available.
- Request-web preview is available.
- Display preview is available.
- OBS/Replay preview docs are available.
- Backup/restore preview docs are available.
- Operator has reviewed known limitations.

## No-go checks

- The host does not understand the manual fallback plan.
- The venue cannot provide a stable local setup.
- The operator has not reviewed the pre-show checklist.
- The system has unreviewed release blockers.
