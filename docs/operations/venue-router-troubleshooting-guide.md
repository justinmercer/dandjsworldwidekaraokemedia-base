
# Venue-Router Troubleshooting Guide

Static venue-router troubleshooting notes.

## Common symptoms

- Guest device cannot reach the local preview.
- Venue network is unstable.
- QR route is unclear.
- Local connection works for one device but not another.

## Safe response

- Confirm the documented route.
- Use manual signup fallback if needed.
- Do not change router, DNS, firewall, or port settings without approval.
