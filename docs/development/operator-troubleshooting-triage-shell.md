
# Operator Troubleshooting and Triage Shell

Wave 14B adds static planning fixtures for troubleshooting, recovery drills, pilot feedback, bug triage, and release-blocker criteria.

## Included

- host troubleshooting guide
- venue-router troubleshooting guide
- OBS companion troubleshooting guide
- recovery drill guide
- first-pilot feedback form
- bug-triage workflow
- release-blocker criteria

## Safety boundary

Wave 14B does not run troubleshooting commands, change routers, connect to OBS, connect to Replay, perform recovery actions, submit feedback, call bug tracker APIs, automate release gates, make network requests, read or write databases, or write runtime files beyond static fixtures and docs.
