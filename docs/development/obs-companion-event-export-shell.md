
# OBS Companion Event Export Shell

Wave 10A adds static shell fixtures for performance-event export planning.

## Included

- performance-start event payload preview
- performance-end event payload preview
- singer name, song, artist, venue, show ID, and timestamp fields
- configurable companion endpoint settings preview
- optional OBS event export module shell
- event-export enable and disable switch preview
- export connection status preview

## Safety boundary

Wave 10A does not connect to OBS, open WebSocket connections, send network requests, call Replay, control playback, write queue records, write performance-event records, write audit history, or store secrets.
