
# Admin Privacy and Security Shell

Wave 11B adds static admin privacy and security planning fixtures.

## Included

- sign-out preview
- failed-login rate-limit preview
- audit logging for sign-ins preview
- audit logging for administrative changes preview
- singer-data privacy notes
- data-retention settings preview
- singer-profile export preview
- singer-profile deletion workflow preview
- staff-account disable workflow preview
- secrets-management documentation placeholder
- security smoke tests

## Safety boundary

Wave 11B does not sign users out, enforce runtime login rate limits, write audit logs, read singer data, export singer profiles, delete singer profiles, disable staff accounts, store secrets, write secrets, write databases, create sessions, or destroy sessions.
