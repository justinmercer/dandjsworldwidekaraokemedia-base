
# Windows Host Playback Controls Shell

Wave 6A starts the playback/audio/external display section with preview-only host playback controls.

## Included

- local media playback engine decision documentation
- local playback state preview
- play preview
- pause preview
- stop preview
- next preview
- previous where safe preview
- fade-out preview
- emergency skip preview
- volume controls preview

## Safety boundary

Wave 6A does not choose or install a real playback engine, play audio, read media files, change output devices, or write playback state. It is UI, documentation, and test-fixture work only.
