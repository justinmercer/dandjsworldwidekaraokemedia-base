
# Mobile PWA and Kiosk Shell

Wave 7D expands the request web app shell with mobile, PWA metadata, accessibility, and kiosk preview fixtures.

## Included

- connection-state display
- offline-friendly static shell cache plan
- installable PWA metadata
- mobile responsive test fixtures
- common iPhone viewport fixtures
- common Android viewport fixtures
- accessibility check markers
- large tap target styling
- shared tablet mode route preview
- kiosk-style large controls

## Safety boundary

Wave 7D does not register a service worker, perform runtime offline caching, submit live requests, call server APIs, write queue records, write singer records, store personal data, or change network mode.
