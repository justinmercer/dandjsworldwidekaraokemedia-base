
# Device Diagnostics and Installer Preview Shell

Wave 12C adds static planning fixtures for device diagnostics and installer setup previews.

## Included

- audio device health check preview
- video output health check preview
- host machine info preview
- diagnostics safe restart note
- installer package placeholder
- Windows installer instructions preview
- first-run setup checklist preview
- update-check placeholder

## Safety boundary

Wave 12C does not probe devices, probe displays, scan machine information, run restart commands, build installers, run update checks, make network requests, or write files beyond static fixtures.
