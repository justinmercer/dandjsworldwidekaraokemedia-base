
# Windows Host Siglos Migration Wizard Shell

Wave 4C adds the Siglos migration wizard shell, preview states, validation messaging, backup-first messaging, summary report preview, and demo fixtures for tests.

## Included

- Siglos migration wizard shell
- song metadata export support preview
- singer profile export support preview
- singer history export support preview
- remembered key-change preview
- venue-entry preview
- saved-preference preview
- migration preview
- migration validation
- duplicate warnings during migration
- backup-first messaging
- migration summary reports
- demo Siglos export fixtures
- Siglos migration tests

## Safety boundary

Wave 4C does not read Siglos files, parse real exports, write catalog records, write singer records, update history, move files, or change local preferences. It is UI, documentation, and test-fixture work only.
