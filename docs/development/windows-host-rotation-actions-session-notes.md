
# Windows Host Rotation Actions, Notes, Snapshots, and Autosave Shell

Wave 5C adds host-side rotation action previews and show-session notes/snapshot/autosave preview states.

## Included

- call singer action preview
- singer not ready action preview
- move to next round action preview
- remove from tonight action preview
- restore singer action preview
- completed performance record preview
- show notes field preview
- manual session snapshot preview
- autosave after meaningful rotation change preview

## Safety boundary

Wave 5C does not change the live rotation, write completed performance records, write show notes, write session snapshots, write files, write browser storage, or persist autosave changes. It is UI, documentation, and test-fixture work only.
