
# Windows Host Catalog Import Wizard Shell

Wave 4A adds the local catalog-import wizard shell for operator-owned or otherwise authorized karaoke media.

## Included

- host-side catalog-import wizard shell
- operator-owned folder-selection placeholder
- supported-file-type detection preview
- filename metadata parsing preview
- manual metadata correction preview
- batch metadata review preview
- duplicate warning display
- alternate-version warning display
- import progress display
- cancellation with safe rollback messaging
- import error summaries
- import review queue placeholder

## Safety boundary

Wave 4A does not scan folders, read media files, write catalog records, create database rows, merge duplicates, move files, delete files, or execute rollback. It is UI and documentation only.
