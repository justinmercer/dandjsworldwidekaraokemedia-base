
# Kiosk Session Shell

Wave 7E finishes the request web app shell section with kiosk session, QR fallback, responsive test, and smoke-test coverage.

## Included

- kiosk idle timeout preview
- kiosk automatic reset preview
- kiosk QR fallback preview
- kiosk responsive test fixtures
- request-web smoke coverage index
- venue-router local request mode documentation

## Safety boundary

Wave 7E does not perform real idle timeouts, reset live kiosk data, generate live QR codes, change router settings, open ports, configure DNS, call server APIs, submit requests, write queue records, write singer records, or store personal data.
