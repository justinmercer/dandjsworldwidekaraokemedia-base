
# Windows Host Display Shell

Wave 6C adds preview-only audience display shell controls to the Windows host.

## Included

- filler-audio volume setting preview
- preview-window plumbing placeholder
- external display window placeholder
- full-screen external display mode placeholder
- display selection placeholder
- cloned display support placeholder
- now-singing card preview
- up-next card preview
- welcome screen preview
- scrolling announcement preview

## Safety boundary

Wave 6C does not open real preview windows, open real external display windows, enter full-screen mode, enumerate monitors, select monitors, clone displays, load background files, use cameras, or write display state.
