
# Demo Mode Screenshot Checklist

Use this checklist when visually reviewing the demo-mode host shell.

## Required screenshots

- main host dashboard with demo mode enabled
- first-run setup dialog
- settings panel showing UI scaling
- loading / empty / error state panel
- toast notification visible
- confirmation dialog visible
- activity log panel
- diagnostics export preview dialog

## Safety boundary

The screenshot checklist is manual documentation only. It does not automate screenshots, write files, run browsers, scan folders, or launch playback.
