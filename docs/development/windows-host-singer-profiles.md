
# Windows Host Singer Profile Model Shell

Wave 5A adds singer-profile model shell UI, privacy-safe demo fixtures, and smoke checks.

## Included

- singer-profile model shell
- singer display names
- optional contact fields with privacy-safe defaults
- staff-only notes preview
- singer favourites preview
- singer song-history preview
- remembered key-change preview
- duet and group performance tags
- singer aliases and merge warning preview
- repeat singer detection warning preview

## Safety boundary

Wave 5A does not write singer records, merge singer records, expose contact details publicly, import real singer history, change rotation, or connect to the mobile request app. It is UI, documentation, and test-fixture work only.
