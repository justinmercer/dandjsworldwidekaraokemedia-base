
# Backup and Restore Preview Shell

Wave 12A adds static planning fixtures for backup, export, and restore previews.

## Included

- HQ metadata backup preview
- singer-history backup preview
- venue-profile backup preview
- show-session snapshot export preview
- host settings backup preview
- restore preview

## Safety boundary

Wave 12A does not perform backups, perform restores, create export files, read databases, write databases, read singer history, read host settings, or write backup storage.
