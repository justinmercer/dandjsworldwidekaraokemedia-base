
# Venue Profile Settings Shell

Wave 9A adds the venue profile and settings shell fixtures.

## Included

- venue-profile model preview
- venue name preview
- venue address fields preview
- venue logo placeholder
- venue contact notes preview
- venue request settings preview
- venue access-code settings preview
- venue local-router notes preview
- venue default display theme preview
- venue announcement text preview

## Safety boundary

Wave 9A does not write venue profile records, upload logos, store files, generate access codes, update router config, change DNS, change ports, change firewall rules, or write runtime settings.
