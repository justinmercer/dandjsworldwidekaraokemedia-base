
# Windows Host Diagnostics and Activity

Wave 3F adds safe UI-only patterns for host diagnostics and local activity feedback.

## Included

- safe error dialog
- toast follow-up action
- local activity log panel
- diagnostics export preview action

## Safety boundary

The diagnostics export action is a placeholder. It does not generate, write, upload, download, or delete files.

The activity log is a UI-only preview. It does not persist logs outside the current browser page in this wave.
