
# Request Workflow Shell

Wave 7B expands the request web app shell with request workflow preview screens.

## Included

- search empty-state copy
- recent-song browsing preview
- popular-song browsing preview
- favourites browsing preview
- singer-history browsing preview
- duet indicators
- alternate-version display
- request submission preview
- optional key-change request preview
- optional duet-partner request preview

## Safety boundary

Wave 7B does not submit live requests, call server APIs, write queue records, write singer records, search a real catalog, store personal data, moderate requests, or send notifications.
