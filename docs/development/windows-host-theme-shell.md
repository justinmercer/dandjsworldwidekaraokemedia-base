
# Windows Host Theme Shell

Wave 6D adds preview-only theme and fallback controls to the Windows host.

## Included

- venue logo overlay preview
- custom background support preview
- camera-background placeholder
- theme selection preview
- private-party theme preview
- wedding theme preview
- bar-night theme preview
- external-display fallback preview
- failure-isolation preview
- demo fixtures only

## Safety boundary

Wave 6D does not load logo files, load background files, use cameras, change monitor state, control the live show, read media files, or write theme state.
