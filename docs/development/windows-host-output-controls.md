
# Windows Host Output Controls Shell

Wave 6B adds preview-only output and tuning controls to the Windows host shell.

## Included

- output-device selection preview
- microphone-recording control placeholders
- key-change controls preview
- tempo controls preview
- reset-to-default controls preview
- playback progress preview
- remaining-time display preview
- end-of-track detection preview
- filler hook preview
- filler enable and disable preview

## Safety boundary

Wave 6B does not enumerate real output devices, select real devices, access the microphone, start recording, play audio, read media files, schedule filler audio, or write control state.
