
# YouTube Ranking Preview Controls Shell

Wave 8C adds quota-friendly search behavior, candidate ranking, and preview-control fixtures.

## Included

- quota-friendly search behavior preview
- candidate ranking preview
- exact title match ranking
- artist match ranking
- karaoke keyword ranking
- instrumental keyword ranking
- tutorial or reaction down-ranking
- embedded YouTube preview player placeholder
- preview play control
- preview pause control
- candidate fixture scoring

## Safety boundary

Wave 8C does not call the YouTube Data API, perform external search, load an embedded player, play media, pause media, download media, write runtime cache records, write queue records, write singer records, or modify catalog records.
